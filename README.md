
# Salary Data Visualization

## Project Description

This project visualizes the relationship between years of experience and salary using Python.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Spyder

## Project Features

* Loads salary data from a CSV file
* Displays the dataset
* Creates a graph showing the relationship between experience and salary
* Helps understand salary trends based on years of experience

## Files

* `salary_graph.py` – Python code for data visualization
* `Salary_Data.csv` – Salary dataset
* `README.md` – Project documentation

## Output

The project generates a graph showing Salary vs Years of Experience.

## How to Run

1. Install Python.
2. Install required libraries:

```bash
py -m pip install pandas matplotlib
```

3. Run the Python file:

```bash
py salary_graph.py
```
